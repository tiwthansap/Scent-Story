# Scent Story — ซอร์สโค้ดเว็บไซต์

เว็บไซต์ขายก้านไม้หอม ทำด้วย HTML/CSS/JavaScript ล้วน ไม่ต้องติดตั้งอะไร ไม่ต้อง build
ดับเบิลคลิก `index.html` เปิดในเบราว์เซอร์ได้เลย

## โครงสร้างไฟล์

```
index.html   โครงหน้าเว็บ (header, hero, section ต่าง ๆ, footer, ตะกร้า)
style.css    ดีไซน์ทั้งหมด — สี ฟอนต์ ระยะห่าง responsive
app.js       ข้อมูลสินค้า + ระบบทั้งหมด (กรองกลิ่น, หน้าสินค้า, ตะกร้า, Scent Finder)
img/         รูปภาพ
  p01–p12.jpg      รูปหลักของสินค้าแต่ละกลิ่น
  d01–d12.jpg      รูปมุมที่สอง (ใช้ในหน้าสินค้า + เซ็ตของขวัญ)
  emblem.png       ตราโลโก้ พื้นหลังโปร่งใส (ใช้บนพื้นสว่าง)
  emblem-light.png ตราโลโก้สีครีม (ใช้บนพื้นสีเข้ม)
  logo-full.png    โลโก้เต็มพร้อมตัวอักษร (ใช้ในหน้า Our Story)
```

## แก้อะไร ที่ไหน

### เปลี่ยนชื่อกลิ่น / ราคา / โน้ตกลิ่น
`app.js` บรรทัดแรก ๆ ที่ตัวแปร `P` — สินค้าหนึ่งกลิ่นคือหนึ่งบล็อก:

```js
{ no:'01',                        // เลข edition ที่โชว์มุมรูป
  en:'Golden Hour',               // ชื่ออังกฤษ
  th:'แสงสุดท้ายของวัน',           // ชื่อไทย
  moods:['warm','woody'],         // กลุ่มกลิ่น ใช้กับปุ่มกรอง
  p1:790,                         // ราคา 100 มล.
  p2:1190,                        // ราคา 200 มล.
  best:true,                      // true = ติดป้าย BEST SELLER
  en_notes:'Amber · Cedarwood · Tonka',   // บรรทัดโน้ตใต้ชื่อในการ์ด
  pyr:['โน้ตหัว','โน้ตกลาง','โน้ตท้าย'],   // ตารางในหน้าสินค้า
  story:'ข้อความเล่าเรื่องกลิ่น' }
```

ค่า `moods` ที่ใช้ได้: `warm` `fresh` `floral` `woody` `clean`
(แก้ชื่อหมวดหรือเพิ่มหมวดได้ที่ตัวแปร `MOODS` ด้านบนสุดของไฟล์เดียวกัน)

### เปลี่ยนรูปสินค้า
เอารูปใหม่ทับไฟล์เดิมใน `img/` โดยใช้ชื่อเดิม (แนะนำสัดส่วนแนวตั้งประมาณ 307:325)
หรือถ้าอยากเปลี่ยนชื่อไฟล์ ให้แก้ path ที่ตัวแปร `IMG` บนสุดของ `app.js`

### เปลี่ยนสีแบรนด์
`style.css` บล็อกแรกสุด `:root{ ... }`

```css
--paper:#F7EEE4;   /* พื้นหลังหลัก สีครีม */
--ink:#2E2018;     /* สีตัวอักษรหลัก น้ำตาลเข้ม */
--gold:#A07535;    /* สีทอง ใช้เป็น accent */
--sage:#7E9079;    /* สีเขียวจากใบไม้ในโลโก้ */
--dark-ground:#251A13;  /* พื้นสีเข้มของแถบ The Ritual และ footer */
```

โหมดมืดอยู่ในบล็อก `@media (prefers-color-scheme:dark)` และ `:root[data-theme="dark"]`
ถ้าแก้สีในโหมดสว่าง อย่าลืมดูสองบล็อกนี้ด้วย

### เปลี่ยนฟอนต์
บรรทัด `<link>` ใน `index.html` (โหลดจาก Google Fonts) และตัวแปร `--serif` `--sans` `--thai` ใน `style.css`

### แก้ข้อความในหน้าเว็บ
ข้อความส่วนใหญ่อยู่ใน `index.html` ตรง ๆ — hero, จุดเด่น 4 ข้อ, วิธีใช้, Gift Set, Our Story, FAQ, footer
ยกเว้นการ์ดสินค้า หน้าสินค้า และ Scent Finder ที่สร้างจาก `app.js`

### ยอดสั่งซื้อขั้นต่ำที่ส่งฟรี
`app.js` ตัวแปร `const FREE = 1000;`

## ข้อควรรู้

- ตะกร้าสินค้าเก็บไว้ในหน่วยความจำของหน้าเว็บเท่านั้น รีเฟรชแล้วหาย
  และปุ่ม "ชำระเงิน" ยังไม่เชื่อมระบบจ่ายเงินจริง — ถ้าจะขายจริงต้องต่อกับ
  ระบบหลังบ้าน เช่น Shopify, WooCommerce หรือ payment gateway ของไทย
- เว็บเป็น static ทั้งหมด อัปโหลดขึ้น hosting อะไรก็ได้ (Netlify, Vercel,
  GitHub Pages, หรือโฮสต์ทั่วไป) แค่อัปทั้งโฟลเดอร์ขึ้นไป
- ข้อความในเว็บ (เรื่องราวแบรนด์ ปีที่ก่อตั้ง ชื่อผู้ก่อตั้ง ข้อมูลติดต่อ
  ช่องทาง LINE/Instagram/อีเมล) เป็นตัวอย่างที่แต่งขึ้น ให้แก้เป็นข้อมูลจริง
  ก่อนนำไปใช้งาน
